# Security

If you believe you have found a security problem in Dungeons & Deploys, please do not open a public issue or post
it as an idea in the game. Report it privately under
[Security → Report a vulnerability](https://github.com/Olesko24/dungeons-and-deploys/security/advisories/new).

This covers the API, the website, the `quest` CLI and the Claude Code plugin. Game exploits that hand out gold,
items or XP count too.
